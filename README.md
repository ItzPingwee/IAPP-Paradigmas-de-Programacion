## 🧠 Paradigmas Explorados

En este curso abordamos tres enfoques principales, cada uno con su propio lenguaje representativo:

1. **Paradigma Lógico (Prolog):** Basado en la lógica formal, donde definimos hechos y reglas, y el motor de inferencia deduce las respuestas.
2. **Paradigma Funcional (Haskell):** Centrado en la evaluación de funciones matemáticas, evitando estados mutables y efectos secundarios.
3. **Paradigma Imperativo/Multiparadigma (Python):** Enfocado en cómo ejecutar las tareas paso a paso, utilizando programación orientada a objetos y scripts estructurados.
